# One-Minute University 🎓

Build your knowledge, one minute at a time.

A zero-backend learning experience built with plain HTML, CSS and JavaScript. Each lesson follows a simple loop:

1. **30 sec — Core concept**
2. **20 sec — Real-world example**
3. **10 sec — Test yourself**
4. Earn XP and move to the next topic

## Current MVP

- Responsive dark UI
- Home / Explore / Profile navigation
- 8 learning categories
- 5 starter lessons
- Timed 30/20/10 second lesson phases
- Multiple-choice recall question
- XP and lesson progress
- Recent learning history
- Local persistence with `localStorage`
- No backend or paid API required

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy for free

This is a static site, so it can be deployed with GitHub Pages or another static host without a backend.
